# Make your Voe workspace useful

An empty workspace is not useful yet. That is fine.

Do not begin by connecting every source you have. Start with a small set of current material, check that Voe kept it properly, and ask one question whose answer matters to your work. Connect your assistant after the record has something worth reading.

Set aside 15 minutes. Bring the inbox that received the invitation, three current email threads, and the private iCal subscription address for your main calendar.

By the end, you should have:

- a Voe email address
- three useful threads in the ledger
- your main calendar subscribed
- one answer whose sources you opened
- Claude or ChatGPT connected, if you use either one

## Claim the workspace

Open the setup link in the invitation email. Confirm that the workspace name is the one you expect, then select **Send code**.

Voe sends a six-digit code to the invited email address. Enter it and select **Open Voe**.

The setup link works once. If it has expired or has already been claimed, ask the person who invited you for a replacement.

## Choose your Voe email address

Review the suggested address and select **Use this address**. Keep it somewhere easy to reach from your mail app.

This is the simplest way to add work to Voe. Forward a message or thread to the address and Voe keeps the message, its source, and the useful material it can support.

Leave the phone setup for later unless calls or text messages carry work you regularly need to revisit.

## Send one real thread

The setup flow asks for a test message. Use a current business thread instead. A real thread gives the first question something useful to work with.

Choose one that contains a decision, a promise, a deadline, or an attachment you may need later. Forward the complete thread to your Voe address, then select **Check now** until the screen says **It landed**.

When setup reaches **Connect**, choose **Skip for now**. First check that Voe can answer from what you sent.

## Ask one question before moving on

Use the question suggested by setup, or ask:

> What did I commit to in the thread I just sent?

Read the answer and open its source. The point of this first question is not to test how much Voe knows. It is to confirm that an answer leads back to the message behind it.

Select **Continue to your dashboard** when setup is complete.

## Add two more threads

Forward two more current threads to the same Voe address. A useful first set usually covers three kinds of work:

1. a customer, deal, or partner conversation
2. an active project or decision
3. a promise, deadline, or open question

Send complete threads when possible. Include attachments that carry the substance of the conversation. Leave newsletters, promotions, and routine receipts for later.

Open **Today** in the dashboard. Your new records should appear in the ledger with the most recent first. Open at least one and check its body, source, and attachments.

## Add the calendar you actually use

Open **Channels**, find **Calendar feeds**, and paste the private ICS or iCal subscription address for your main calendar. Select **Subscribe**, then **Sync now** on the new calendar row.

![The Channels view with the workspace email address and calendar subscription field.](./assets/images/blog/first-useful-workspace/channels.png)

The **Where is my calendar's ICS URL?** link has provider-specific instructions. For Google Calendar, use the **Secret address in iCal format**, not a public browser or embed link.

Voe reads this calendar source. It does not sign in to the calendar account or change events.

Return to **Today** and open one calendar event from the ledger. You now have correspondence and scheduled work in the same record.

## Check anything held for review

Look at the count beside **Needs your eye**.

A normal forward or a new sender does not require approval simply because it is new. If Voe holds a record, the review screen names the reason. Open the item, inspect the original, and release it only when you recognize it.

If the count is zero, there is nothing to do.

## Ask a question that saves work

Return to **Today** and use **Ask your memory**. Ask about work you will act on, not the product itself.

Good first questions include:

- What have I promised this week?
- What do I need before my next call with [name]?
- What changed across the threads about [company or project]?
- Which decisions and deadlines appear in the record?
- What is missing before I act on [topic]?

Open the cited records in the answer. Read **What I don't know** as carefully as the answer itself. If something important is missing, forward the thread or attachment that carries it and ask again after it appears in **Today**.

Voe starts with material received after the workspace opens. Forward older threads when they matter to a current question.

## Connect the assistant you already use

Now the workspace has enough substance for an assistant connection to be useful.

Open **Connect an agent** and choose **Claude Desktop** or **ChatGPT**. Copy the connector address shown on screen. In the assistant's connector settings, add a custom connector named `Voe`, paste the address, and complete the browser approval.

![The Connect an agent view with Claude Desktop, Claude Code, ChatGPT, and API options.](./assets/images/blog/first-useful-workspace/connect-agent.png)

Return to Voe and confirm that the assistant appears under **Connected assistants**.

The connection reads this workspace. It does not add records unless you separately enable that ability. Leave **Let an assistant add records** closed until you have a specific reason to use it.

## Keep it useful without tending it all day

The useful habit is small:

- forward conversations when they become important
- keep the main calendar subscribed
- open **Needs your eye** only when it shows a count
- use **Gaps** when Voe names missing context
- ask before a meeting, decision, or follow-up

Add another source only when it carries work you expect to revisit. More material is not the goal. A record that helps with the next decision is.

## If something does not appear

**The setup code did not arrive.** Check the invited mailbox and its spam folder. Confirm that the invitation went to the address you are checking. Ask for a replacement if the setup link has expired.

**A forwarded message is missing.** Confirm the Voe address, then check **Today** and **Needs your eye**. During setup, use **Check now**. Send the full message again only after confirming that the first copy did not arrive.

**Calendar events are missing.** Confirm that you used a private ICS or iCal subscription address, then return to **Channels** and select **Sync now**.

**An answer is incomplete.** Open its sources and read **What I don't know**. Forward the complete thread, attachment, or other source that carries the missing detail, then ask again.

**The assistant does not connect.** Copy the current address from **Connect an agent**, complete the browser approval, then refresh the dashboard and check **Connected assistants**.

That is enough for the first day. Three useful threads, one calendar, and one question grounded in material you can open.
